# C2X86 1.0.0

First desktop release: translate between 13 languages with OpenAI, Gemini, or a local GGUF model. Includes syntax-highlighted editors, import/export, find/replace, cancellation, cached local models, preferences, and optional local draft recovery.

Choose the archive matching your operating system and CPU. Extract the entire folder; .NET is included. API keys and local model weights are supplied by you. See the included READ-ME.md for launch instructions and checksums.

Windows/Linux x64 and experimental Intel/Apple Silicon macOS packages are provided. Downloads are unsigned and macOS builds are not notarized. Cross-platform builds and automated tests do not establish GUI or native-model compatibility on every machine. Review and test all generated code; the application never executes it.
